# Test Tasks

Набор из трёх интерактивных задач, выполненных в рамках тестового задания.

## 🎮 Задачи

### Task 1 — Scroll Image Sequence
Анимация последовательности изображений, которая воспроизводится при прокрутке страницы.

**Что реализовано:**
- переключение кадров при скролле
- 27 изображений в последовательности
- защита от выхода за пределы диапазона

### Task 2 — Parallax Slider
Интерактивный слайдер с эффектом параллакса и motion blur.

**Что реализовано:**
- переключение слайдов кликом по левой/правой части экрана
- motion blur при смене слайда
- параллакс-движение элементов при движении мыши

### Task 3 — Drag & Drop
Перетаскивание элемента по экрану.

**Что реализовано:**
- плавное перемещение элемента
- корректное вычисление позиции курсора
- центрирование при загрузке страницы
